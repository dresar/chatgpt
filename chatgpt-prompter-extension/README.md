# 🚀 AI Multi-Tab Batch Prompter Pro (ChatGPT & Google Gemini Master v2.0)

Sidebar Chrome Extension canggih untuk mengotomatisasi pembuatan gambar dan konten secara batch simultan di **ChatGPT** (`https://chatgpt.com/`) dan **Google Gemini** (`https://gemini.google.com/`) dengan fitur:
- 👥 **Multi-Tab & Multi-Platform Paralel**: Bisa mencampur tab ChatGPT dan tab Google Gemini sekaligus!
- 📁 **Multi-File Upload & Drag-and-Drop**: Upload 10 hingga puluhan file prompt `.txt` / `.json` dalam sekali klik.
- 💾 **Smart Database & Auto-Archive**: Slide yang selesai otomatis diarsipkan ke Database (`database.json`) agar antrean tidak nyangkut.
- 📂 **Folder Kustom Per-Tab**: Menentukan folder penyimpanan unduhan yang berbeda untuk setiap tab ChatGPT/Gemini dengan tombol pemilih folder Windows (`📂 Pilih`).
- 🧠 **Smart Error Auto-Recovery**: Mendeteksi error server internal (*"kesalahan di pihak saya"* / *"terjadi masalah"*) dan otomatis mengirim perintah pemulihan.
- 📥 **Direct HD Downloader**: Menyimpan gambar kualitas asli resolusi tinggi tanpa perlu screenshot.

---

## 🛠️ CARA MEMASANG / MEMPERBARUI DI GOOGLE CHROME

1. Buka browser **Google Chrome**.
2. Masuk ke: `chrome://extensions`
3. Nyalakan sakelar **"Developer mode"** (Mode Pengembang) di kanan atas.
4. Klik tombol **"Load unpacked"** (atau klik ikon **🔄 Refresh** jika sudah terpasang) dan pilih folder:
   ```text
   C:\Users\NCN0C\Videos\CHATGPT\chatgpt-prompter-extension
   ```
5. Buka tab **ChatGPT** (`https://chatgpt.com/`) atau **Google Gemini** (`https://gemini.google.com/app`).
6. Klik ikon extension di pojok kanan atas Chrome untuk membuka sidebar! 🎯
